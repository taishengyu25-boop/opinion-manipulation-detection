# Model

本目录用于存放舆论操控文本检测模型。

## Model Information

- Base Model: ZhipuAI/GLM-4-9B-0414
- Fine-tuning Method: LoRA
- Task: 舆论操控文本二分类
- Number of Classes: 2
- Class 0: 非舆论操控
- Class 1: 舆论操控
