# 基于理论引导与策略约束生成的舆论操控文本检测方法

本项目为论文《基于理论引导与策略约束生成的舆论操控文本检测方法》提供模型推理代码、示例数据及模型使用说明。

针对生成式人工智能场景下舆论操控检测任务中真实训练数据不足、操控手段覆盖不充分等问题，本文提出一种**基于理论引导与策略约束生成的舆论操控文本检测方法**。该方法引入认知操控理论作为先验知识，将抽象的操控策略细化为网络文本中的具体操控手段，并以细粒度操控手段作为显式策略约束，引导大语言模型生成具有不同操控特征的训练样本，进一步通过参数高效微调构建舆论操控文本检测模型。

本仓库主要提供训练完成后的检测模型及推理代码。用户无需重新训练模型，即可加载模型并对输入文本进行舆论操控识别。

本文将舆论操控视为一种可以通过文本表达进行识别的语言现象，通过建立**操控策略—具体操控手段—文本表达特征**之间的关联，使检测模型能够学习不同类型舆论操控行为的语言表现。

## 2. 舆论操控手段体系

本文基于六度操纵理论构建细粒度舆论操控手段体系。

最终形成：

- **6类基础操控策略**
- **277种具体操控手段**

六类基础策略包括：

| 类别 | 中文名称 | 英文名称 |
| :--- | :--- | :--- |
| 1 | 冒充 | Impersonation |
| 2 | 阴谋论 | Conspiracy |
| 3 | 情绪操控 | Emotion |
| 4 | 极化 | Polarization |
| 5 | 污名化 | Discrediting|
| 6 | 恶意引战 | Trolling |

细粒度操控手段体系用于描述不同操控策略在网络文本中的具体表现形式，并进一步作为数据生成阶段的策略约束信号。

---

## 3. 数据生成

本文采用真实公共议题问答作为文本生成语境。

数据生成过程主要包括：

1. 从真实公共议题数据中获取问题及官方回答；
2. 根据目标操控策略选择对应的细粒度操控手段；
3. 将操控手段及其定义作为显式策略约束；
4. 通过大语言模型进行受控文本生成；
5. 对生成结果进行质量筛选和数据整理。

与直接要求大语言模型生成“舆论操控文本”不同，本文将具体操控手段作为生成过程中的控制变量，使生成文本能够覆盖不同的操控表达模式。

由于部分生成过程涉及安全对齐限制，本文使用经过适当处理的非安全对齐生成模型完成受控数据生成。相关生成模型及具体使用方式不属于本仓库的主要推理内容。

## 4. 检测模型

本文基于生成的舆论操控样本和真实良性样本构建检测数据，并采用参数高效微调方法训练舆论操控检测模型。

### 基础模型

本研究对多个8B级开源大语言模型进行了实验，包括：

- Qwen3-8B
- GLM-4-9B-0414
- InternLM3-8B-Instruct
- Meta-Llama-3.1-8B

本仓库提供其中一个训练完成的检测模型用于推理示例。

### 微调方法

采用 Low-Rank Adaptation（LoRA）进行参数高效微调。

主要配置包括：

```text
LoRA Rank: 8
LoRA Alpha: 16
LoRA Dropout: 0.05
Learning Rate: 2e-5
Optimizer: AdamW
Precision: BF16
```

具体模型配置以 `model/README.md` 中的说明为准。

## 5. 实验结果

本文从同源测试、跨来源测试以及真实业务测试三个场景评估检测模型性能。

### 5.1 同源测试

在与训练数据具有相同任务分布的测试集上，经过LoRA微调后的多个开源大语言模型均取得较高的检测性能。

其中：

| 模型 | Accuracy | Precision | Recall | F1-score |
| :--- | ---: | ---: | ---: | ---: |
| Qwen3-8B | 99.4% | 100.0% | 98.8% | **99.4%** |
| GLM-4-9B-0414 | 99.5% | 99.2% | 99.9% | **99.5%** |
| InternLM3-8B-Instruct | 96.7% | 100.0% | 93.2% | **96.5%** |
| Meta-Llama-3.1-8B | 96.2% | 93.0% | 99.8% | **96.3%** |

实验结果表明，针对性训练能够显著增强通用大语言模型对舆论操控文本的识别能力。

---

### 5.2 跨来源测试

为了进一步评估模型的泛化能力，本文构建了与训练数据来源和表达形式存在差异的跨来源测试集。

结果如下：

| 模型 | Accuracy | Precision | Recall | F1-score |
| :--- | ---: | ---: | ---: | ---: |
| Qwen3-8B | 92.7% | 92.9% | 92.5% | **92.7%** |
| GLM-4-9B-0414 | 92.9% | 92.0% | 94.0% | **93.0%** |
| InternLM3-8B-Instruct | 90.3% | 94.8% | 85.2% | **89.8%** |
| Meta-Llama-3.1-8B | 79.6% | 87.5% | 69.0% | **77.1%** |

尽管跨来源测试中的模型性能相较同源测试有所下降，但主要模型仍保持较高的检测性能，说明模型能够在一定程度上利用操控策略对应的语义和表达特征，而不仅依赖训练数据中的表层表达模式。

---

### 5.3 真实业务测试

本文进一步使用真实业务场景中的独立测试数据评估模型迁移能力。

结果如下：

| 模型 | Accuracy | Precision | Recall | F1-score |
| :--- | ---: | ---: | ---: | ---: |
| Qwen3-8B | 84.3% | 80.2% | 82.6% | **81.4%** |
| GLM-4-9B-0414 | 85.2% | 85.7% | 77.3% | **81.3%** |
| InternLM3-8B-Instruct | 83.0% | 90.6% | 65.9% | **76.3%** |
| Meta-Llama-3.1-8B | 73.9% | 65.0% | 80.3% | **71.9%** |

真实业务测试结果表明，经过针对性训练的检测模型能够在不同于训练数据的真实应用环境中保持一定的舆论操控识别能力。

## 7. 模型推理

### 7.1 交互式预测

执行：

```bash
python inference.py
```

程序启动后输入待检测文本：

```text
请输入待检测文本：
> 某些人一直在刻意隐瞒真相，普通群众根本没有机会知道真正发生了什么。
```

模型输出：

```text
预测结果：舆论操控
```

再次输入正常文本：

```text
请输入待检测文本：
> 今天国务院新闻办公室举行新闻发布会，介绍相关政策实施情况。
```

模型输出：

```text
预测结果：非舆论操控
```

---

### 7.2 命令行预测

也可以直接通过命令行指定待检测文本：

```bash
python inference.py --text "这里输入需要检测的文本"
```

例如：

```bash
python inference.py --text "某些人一直在刻意隐瞒真相。"
```

输出示例：

```text
预测结果：舆论操控
```

具体命令参数以当前版本 `inference.py` 为准。
